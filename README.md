# Gal Link · 资源搜索

在 QQ 群里 @ AstrBot，用自然语言查找 Galgame 资源。各站点并发检索，优先使用游戏的中文名和中文昵称。单个站点未命中时，再使用日文和英文标题查询，汇总下载入口、网盘分享和资源页。

## 安装

需要 **AstrBot `>=4.29.4,<5`**，并已接入 **QQ OneBot（`aiocqhttp`）**。

1. 打开 AstrBot WebUI 的「插件 → 安装插件 → 从链接安装」。
2. 粘贴下面的仓库地址，安装后在「已安装」页确认 **Gal Link · 资源搜索** 已启用。

   ```text
   https://github.com/maruyui-dev/astrbot_plugin_gal_link
   ```

本地开发时，可将仓库克隆到 `AstrBot/data/plugins/astrbot_plugin_gal_link`，在 AstrBot 的 Python 环境中安装 [依赖](./requirements.txt)，然后在 WebUI 重载插件。更多安装方式见 [AstrBot 插件文档](https://docs.astrbot.app/use/plugin.html#从仓库或文件安装)。

## 群聊用法

发起查询时，用 QQ 的 @ 功能选中本机器人，再输入查询内容。收到选择菜单或分页结果后，可以直接回复，也可以 @ 本机器人后回复。

| 发送 | 用途 |
| --- | --- |
| `我想玩千恋万花` | 按作品名搜索资源 |
| `给我一个千恋万花的安装包` | 用自然语言提出资源请求 |
| `查询千恋万花`、`帮我检索一下千恋万花`、`找一找千恋万花` | 按作品名查找资源 |
| `《千恋万花》` | 直接用书名号指定作品 |
| `星白`、`找一下星白` | 列出与「星白」相关的作品供选择 |
| `天使` | 列出名称与「天使」相关的作品 |
| `1 2` | 在平台选择提示后，多选 APK 和 Windows |
| `1` | 在作品候选列表后，选择第 1 个候选 |
| `0` | 退出当前平台或作品选择 |
| `下一页` | 查看后续结果 |

普通聊天由 AstrBot 处理，已匹配的其他插件指令优先。编号和分页只对同一群里的原请求人有效，交互状态在 10 分钟后过期，翻页会刷新有效期。

### 平台与运行方式

发起资源查询后，机器人会先提示选择平台或运行方式：

```text
请选择需要的平台或运行方式（支持多选）：
1. APK（安卓直装）
2. Windows（电脑端）
3. iOS（苹果手机 / iPad）
4. Ty（Tyranor 模拟器）
5. KRKR（吉里吉里模拟器）
6. ONS（ONS 模拟器）
7. 不限平台
0. 退出
请由发起查询的群友直接回复序号，也可以 @ 本机器人后发送。
多选用空格或逗号分隔。
例如：1 2，表示同时查找 APK 和 Windows 资源。
选择「7」表示不限平台，本次选择在 10 分钟内有效。
```

平台菜单发出后，机器人等待原查询人回复。如果收到非数字文字，会提示一次如何选序号。支持 `1 2`、`1,2`、`1，2`、`1、2`，重复序号自动合并。包含 `7` 时按不限平台处理。单独回复 `0` 可退出。平台编号与作品编号分别接收，选择作品后会保留之前的平台筛选。

完成平台选择或作品候选选择、开始检索时，会先回复「收到，正在查找《作品名》的资源，请稍等。」，再发送查询结果、作品候选或未命中提示。显示平台选项、输入无效序号和查看「下一页」时不会额外发送查找提示。

结果按所选类型的并集筛选，筛选后再分页，「下一页」保持相同范围。类型以站点的平台字段或资源标签为准。PC / Windows 归为 Windows，APK / 安卓直装归为 APK，iOS / IPA 归为 iOS，并识别对应模拟器名称。类型不明的资源只在不限平台时显示，例如只有文件名、没有平台标注的网盘文件。

各站点仍并发检索。每个站点优先查询中文名及中文昵称，没有所选类型的中文结果时，再使用日文和英文标题查询；其他类型的命中不会阻止语言回退。

未找到所选类型时，会在同一条回复里说明缺少的类型，并提示原请求人直接回复 `7` 查看不限平台的结果，或重新选择其他类型。不会自动改为其他平台；部分站点查询失败时会另行注明。作品名存在歧义时会列出候选，用户选定作品后继续按之前的平台范围查询。

候选列表出现后，发起查询的群友可以直接回复作品序号。单独 @ 本机器人可以再次查看当前选择的操作提示。

### 命中示例

```text
找到《千恋万花》
共 5 条资源 · 第 1 / 2 页

1. 真红小站
名称  千恋万花.7z
解压码  原站未注明
下载  xxx

2. 喵喵盘
名称  千恋万花.zip
已找到 2 个分卷
解压码  示例解压码
千恋万花01.zip  下载  xxx
千恋万花02.zip  下载  xxx
目录  xxx

3. 稻荷ACG
名称  千恋万花安卓直装
类型  APK
解压码  原站未注明
夸克网盘  xxx

还有 2 条资源。直接发送「下一页」即可，也可以 @ 本机器人后发送。
请由发起查询的群友在 10 分钟内操作。
```

这是格式示例，链接用 `xxx` 代替。找到 `xxx01.zip`、`xxx.part1.rar` 或 `xxx.7z.001` 等分卷时，真红小站、喵盘和喵喵盘会查看命中项的公开上级目录，将同组各卷按序号列在一条结果中。梓澪の妙妙屋按接口返回的文件路径归组。来源只提供网盘分享页时，回复会保留分享链接，注明百度、夸克、迅雷等网盘名称，并保留链接自带的提取参数。

链接前会显示原站公开标注的解压码。优先读取资源说明或所在目录说明。喵盘 GalGame 区缺少单独说明时，使用首页公告公布的默认码。同组分卷共用的码只显示一次，分别标注的不同码跟随各卷链接。未找到解压码时显示「原站未注明」。网盘提取参数留在分享链接里。

### 纠错示例

```text
「星空与白」可能对应以下作品。

1. 星空列车与白的旅行
2. 星空的记忆
0. 退出

直接回复作品序号即可，例如「1」，也可以 @ 本机器人后发送。
请由发起查询的群友在 10 分钟内操作。
```

插件用 VNDB 核对标题和别名，也可借助当前会话的聊天模型识别错字。作品展示名优先采用中文名或中文别名，例如《甜蜜女友》。完成平台选择后，能唯一匹配的完整作品名和高度可信的错字会直接检索。简短关键词、差异较大的简称和相近作品会先列出候选，回复作品编号后才查询资源站。已确认作品且各站无命中时，会统一提示暂无可用资源。

## 站点与配置

| 站点 | 回复中的入口 |
| --- | --- |
| [真红小站](https://www.shinnku.com/) | 公开下载链接 |
| [梓澪の妙妙屋](https://gal.games/) | 公开下载链接或公开网盘分享 |
| [喵盘](https://catcat.cloud/GalGame) | 公开下载链接 |
| [喵喵盘](https://pan.mmpan.top/) | 公开下载链接 |
| [稻荷 ACG](https://inarigal.com/) | 公开网盘分享或资源页 |
| [TouchGal](https://www.touchgal.ink/) | 官方 API 返回的资源页，需配置 Token |

单个站点没有命中时会从回复中省略。下载入口和网盘链接由原站提供，使用时以站点当前状态为准。

前五个站点开箱即用。要启用 TouchGal，请在 [开发者门户](https://developer.touchgal.com/) 申请访问，获批后在 AstrBot WebUI 的 Gal Link 插件配置里填写「TouchGal 官方 API Token」。该字段默认为空，官方 API 提供资源页入口。详见 [TouchGal API 文档](https://developer.touchgal.com/docs/api/game-resources)。

## 整点提醒

在 AstrBot WebUI 中打开 Gal Link 的插件配置，在「群发白名单」里选择需要提醒的 QQ 群聊会话，然后保存并重载插件。选择器显示群名和所属机器人，可通过 `/sid` 获取群会话的 UMO，手动添加时使用完整的 `平台实例ID:GroupMessage:群号`。

提醒按北京时间（`Asia/Shanghai`）发送，每天 07:00—23:00 和 00:00 各发送一次，共 18 次。白名单默认为空，填入后仅向选中的群聊发送。该设置用于提醒群发，资源查询按群聊消息正常触发。

需要立即发送时，开启「立即群发一次」并点击保存。AstrBot 保存配置后会自动重载插件，随即向当前白名单里的群聊发送一次相同提醒，不受整点发送时段限制。该开关默认为关闭，执行前会自动复位并保存，避免下次重载或重启时重复发送；白名单为空时不会发送或保留待发请求。重新打开插件配置即可看到已复位的状态，需要再次发送时重新开启并保存。

提醒示例如下。第二行会真实 @ 发送提醒的机器人，末行使用发送时的北京时间，各行之间没有空行。

```text
想找哪部 Galgame 的资源，发个游戏名就行，简称也可以。
例如 @{机器人昵称} 查找千恋万花
现在是 {当前日期} {当前时间}。
```

## 开发与反馈

群消息处理和分页位于 [`main.py`](./main.py)，作品标题匹配位于 [`titles.py`](./titles.py)，站点适配位于 [`sources.py`](./sources.py)。插件放在 `data/plugins/astrbot_plugin_gal_link` 下时，可从 AstrBot 根目录运行测试。

```bash
python -m unittest data.plugins.astrbot_plugin_gal_link.test_gal_link
```
